A standalone Node 22 GitHub-compatible forge built for make.fun's “Build a GitHub-compatible git forge” bounty. It implements persistent repositories, Git smart HTTP, REST v3, GraphQL, and MCP using only Node standard-library modules.

## Run it

```sh
node --experimental-strip-types main.ts
```

The process binds an ephemeral port, registers with `MAKEFUN_ENV_URL`, and serves until the suite reports completion.
